# Databricks Training – Week 1 Day 1

## Overview
This repository contains the SQL practice work completed during Day 1 of the Databricks Training program. The exercises were focused on understanding core SQL concepts through hands-on practice using Employee, Department, and Project datasets.

The objective of this session was to strengthen foundational SQL skills and gain practical experience in querying relational databases.

---

## Topics Covered
- Basic SQL Queries (`SELECT`, `WHERE`)
- Pattern Matching using `LIKE`
- String Functions
- Date and Time Functions
- Aggregate Functions (`SUM`, `AVG`, `COUNT`)
- Data Grouping using `GROUP BY`
- Filtering grouped data using `HAVING`
- Sorting results with `ORDER BY`
- Table Joins
  - `INNER JOIN`
  - `LEFT JOIN`
